CaskTown Regenerated Sprite Pack v1

Contents
- 7 regenerated sprite-sheet PNG files
- 7 matching JSON metadata files
- pack_manifest.json

JSON format
- TexturePacker-like structure with frames + meta
- Origin: top-left
- Coordinates in pixels
- Grid slicing metadata is embedded in meta.grid

Notes
- These files are rebuilt from the regenerated cut-friendly sheets, not from the earlier setting-book composite sheets.
- The JSON files are intended to let you cut the sheets in-engine or by script quickly.
