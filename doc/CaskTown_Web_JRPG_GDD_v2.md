# 《木桶镇 / CaskTown》网页版 JRPG 游戏设计文档 v2.0

> 目标版本：网页版可玩完整主线 Demo → 完整版 Web JRPG  
> 游戏类型：2D 顶视角剧情驱动 JRPG  
> 目标平台：PC 浏览器优先，兼容移动端触屏  
> 推荐引擎：Phaser 3 / PixiJS + 自研状态机，或 Godot Web Export  
> 美术方向：复古像素 JRPG，明亮童话村镇 + 神域水晶圣殿 + 暗黑魔宫

---

## 1. 产品定位

《木桶镇 / CaskTown》是一款面向浏览器平台的传统 2D JRPG。玩家扮演少年 T，与慧慧、A、葱葱、sun 等伙伴从被魔头侵袭的木桶镇出发，寻找三件神物重建家园，进入生命之泉追索 xiaoai 堕魔真相，最终发现真正敌人并非某个魔王，而是在人心深处繁殖的黑暗。

游戏核心体验由四部分构成：

1. **剧情探索**：顶视角地图移动、调查、NPC 对话、事件触发。
2. **回合制战斗**：四人出战、速度排序、技能消耗、属性克制、状态异常、Boss 阶段机制。
3. **家园重建**：主线神物 + 支线资源推动木桶镇从荒芜恢复到繁荣，解锁商店、训练、支线和结局条件。
4. **预言之书系统**：任务日志、地图、怪物图鉴、战斗提示、剧情回顾、分支记录统一由“预言之书”承载。

## 3. 核心设计支柱

### 3.1 童话外壳，悲悯内核

画面整体明亮、角色可爱、对白带有轻松吐槽，但核心剧情围绕家园毁灭、守护兽牺牲、警世者堕落、人心黑暗展开。游戏不追求成人化黑暗，而是采用“童话式残酷”：死亡与失去存在，但总有可被重建的希望。

### 3.2 地图、叙事、系统三位一体

所有主线目标都必须在地图上造成可见变化：

- 取得千年树种后，木桶镇草地和树木恢复。
- 取得神水后，泉水、水井、农田和药草商店恢复。
- 取得神之桂冠后，会场、神坛、训练场和防御设施恢复。
- 解放祀神四体后，生命之泉外壁消失，地图出现新的光路。
- 净化 xiaoai 后，魔宫入口变为“人心之渊”入口。

### 3.3 预言不是提示，而是谜题

预言之书不会直接告诉玩家“去哪里杀谁”，而是用诗句、图标、木桶精灵吐槽和地图碎片给出方向。玩家可以选择：

- 看“简易提示”：直接显示目的地。
- 看“原始预言”：保留诗句和谜面。
- 关闭提示：只保留地图标记。

### 3.4 战斗节奏短、Boss 机制明确

网页版需要避免传统 JRPG 过长战斗。普通战控制在 30–90 秒，Boss 战控制在 3–7 分钟。每场 Boss 至少有一个清晰机制：机关、状态、护盾、阶段、弱点切换或剧情打断。

## 5. 游戏循环

### 5.1 核心循环

```text
接受预言 / 任务
→ 探索区域
→ 对话与调查
→ 小型谜题或机关
→ 普通战斗获取经验和材料
→ Boss 战推进剧情
→ 获得关键道具 / 新技能
→ 木桶镇重建或新区域解锁
→ 回到预言之书更新目标
```

### 5.2 地图探索循环

1. 进入地图，显示区域标题。
2. 木桶精灵弹出一句提示或吐槽。
3. 玩家探索、拾取、对话、触发事件。
4. 走入敌人视野或踩入战斗点进入战斗。
5. 完成机关或击败 Boss，地图状态改变。
6. 预言之书自动记录新条目。

### 5.3 重建循环

```text
主线神物 / 支线材料
→ 回木桶镇提交
→ 建筑/景观恢复
→ 新 NPC 返回
→ 商店和支线解锁
→ 队伍获得长期增益
```

## 9. 战斗系统

### 9.1 基础规则

- 回合制，基于速度决定行动顺序。
- 我方最多 4 人出战，1 人后备；进入第三篇后支持 5 人队伍编成。
- 普通攻击不消耗 MP，技能消耗 MP 或 TP。
- TP 通过受到攻击、造成伤害、防御、触发弱点获得，最高 100。
- Boss 战中死亡角色可用道具复活，但同一场 Boss 复活次数受难度限制。

### 9.2 战斗指令

| 指令 | 功能 |
|---|---|
| 攻击 | 使用当前武器普通攻击，可能触发武器特效 |
| 技能 | 使用职业技能、魔法、治疗、特殊技 |
| 防御 | 本回合伤害 -50%，异常命中率 -30%，获得 TP |
| 道具 | 使用消耗品、战斗道具、复活药 |
| 换人 | 后期开放，与后备角色交换，消耗行动 |
| 逃跑 | 普通战可用，Boss 战不可用 |
| 木桶 | 使用七彩木桶功能，如回护、共鸣、脱离迷宫 |

### 9.3 属性体系

| 属性 | 克制 | 被克 | 典型角色 / 敌人 |
|---|---|---|---|
| 火 | 木、冰 | 水 | A、麒麟、魉 |
| 水 | 火、毒 | 雷 | 水瑶、圣水殿敌人 |
| 风 | 毒、暗雾 | 土 | 慧慧、风赤、葱葱 |
| 土 | 雷、物理 | 风 | A、防御人、玄武殿 |
| 雷 | 水、机械 | 土 | 葱葱后期技能 |
| 木 | 土、毒 | 火 | 奇妙森林、千年树种 |
| 光 | 暗、迷惘 | 无 | T、sun、祀神 |
| 暗 | 光、心智 | 光 | xiaoai、魑魅魍魉 |
| 无 | 无 | 无 | 普通物理 |

### 9.4 弱点与破势

敌人被弱点属性命中会积累“破势值”。破势值满后进入 1 回合“破势”状态：

- 受到伤害 +30%。
- 无法使用蓄力技。
- Boss 阶段技能会被打断。
- 我方获得额外 TP。

### 9.5 状态异常

| 状态 | 效果 | 解除方式 |
|---|---|---|
| 中毒 | 每回合损失最大 HP 5%，魑毒为 8% | 解毒草、御疗术 |
| 迷惘 | 30% 概率随机行动 | 清心铃、sun 祝福 |

## 18. 验收标准

### 18.1 核心体验验收

- 玩家 5 分钟内理解移动、对话、调查、战斗。
- 第一场普通战不超过 60 秒。
- Boss 机制能在预言之书或战斗提示中被理解。
- 每取得一个主线神物，木桶镇必须有明显变化。
- 所有主线剧情可以不查攻略完成。
- 所有重要分支在预言之书中可回看。

### 18.2 网页性能验收

- 首屏加载目标小于 5 秒，完整资源可分包加载。
- 常规地图稳定 60 FPS，移动端最低 30 FPS。
- 存档写入小于 200ms。
- 切换地图小于 2 秒。
- 战斗进入和退出小于 1 秒。

## 19. 设计结论

《木桶镇 / CaskTown》的网页版设计应优先保证三件事：

1. **轻量但完整的传统 JRPG 手感**：键盘操作顺畅、战斗短平快、地图探索清晰。
2. **预言之书与七彩木桶的辨识度**：让它们成为与普通 JRPG 区分开的核心机制。
3. **重建家园的可见反馈**：玩家每推进一次剧情，都能看到木桶镇变好，从而让“重建家园”成为真正的主体验。
