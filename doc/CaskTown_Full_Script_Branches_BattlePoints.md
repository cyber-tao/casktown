### 1.2 对话格式

```text
[SCENE_ID] 场景名
地点：MAP_ID / 区域

  A. 选项文本 → 结果
  B. 选项文本 → 结果
```

### 1.3 全局分支变量

| 变量 | 类型 | 默认 | 说明 |
|---|---|---:|---|
| `trust_huihui` | int | 0 | 慧慧信赖 |
| `trust_a` | int | 0 | A 信赖 |
| `trust_congcong` | int | 0 | 葱葱信赖 |
| `trust_sun` | int | 0 | sun 信赖 |
| `mercy_score` | int | 0 | 悲悯值，影响真结局 |
| `rebuild_level` | int | 0 | 木桶镇重建等级 |
| `prophecy_hint_mode` | enum | light | 预言提示模式 |
| `xiaoai_memory_fragments` | int | 0 | xiaoai 记忆碎片数量 |
| `white_tiger_respected` | bool | false | 是否完整安葬白虎 |
| `answered_xiyuan_kindly` | bool | false | 是否善意回答熙苑 |
| `released_four_seals` | bool | false | 是否释放祀神四体 |
| `normal_ending_seen` | bool | false | 是否看过普通结局 |
| `true_route_unlocked` | bool | false | 真结局是否开启 |

### 1.4 真结局条件

真结局入口在净化 xiaoai 后开启。条件如下：

| 条件 | 要求 |
|---|---|
| 悲悯值 | `mercy_score >= 5` |
| 白虎 | 安葬白虎并听完悼诗 |
| 熙苑 | 最后一题选择善意回答 |
| 祀神 | 释放四封印 |
| 轮回道 | 在 60 秒内与过去的 xiaoai 完成三句关键对白 |
| 战斗 | 地下魔宫 xiaoai 战中使用“戒光净化”而非终结攻击 |

# 2. 序章：盛典之日

## SCN_001 起床与慧慧催促

地点：MAP_001 木桶镇·T 的家门口  
触发：新游戏开始  
队伍：T  
战斗点：无  
分支：BR_001 是否答应帮菠萝大叔

旁白：木桶镇的清晨总是来得很慢。风从生命之泉的方向吹来，带着一点水声，也带着一点梦还没有醒的味道。

HH：T！你还在磨蹭吗？今天可是盛典！

T：听见了，听见了。盛典又不会长脚跑掉。

HH：会跑掉的是你。去年你睡到镇长念完开场词才到。

T：那不正好？省下我站着听大伯咳嗽半天。

HH：不许这么说镇长！还有，菠萝大叔让你帮他整理菜园子。你弄完就早点去会场。

T：为什么是我？

HH：因为你答应过。

T：我什么时候答应的？

HH：昨天你吃了他三个菠萝饭团的时候。

T：……那叫交易，不叫答应。

HH：交易也要付钱。你没钱，所以去干活。

选择：

A. “好吧，我去。”  
→ `trust_huihui +1`，开启菜园教学。

B. “我先去会场。”  
→ 慧慧拦住，强制接受任务，但 `trust_huihui` 不增加。

C. “我再睡五分钟。”  
→ 慧慧用袖镖钉住 T 的衣角，播放小动画；`trust_huihui +1`，获得成就“差点迟到”。

HH：我先去会场帮忙。你不许偷懒。

T：你对我是不是有什么误解？

HH：没有，我很了解你。

系统：获得任务【整理菜园子】。

# 8. 支线分支设计

## 8.1 慧慧支线：不想再迟到的人

触发：重建 Lv.2 后，夜晚与慧慧对话。

核心：慧慧一直催促 T，不只是因为毛躁，而是小时候 T 的父母战死时，她也是“迟了一步”才知道消息。

分支：
- 安慰她：`trust_huihui +2`, `mercy_score +1`。
- 开玩笑转移：`trust_huihui +1`。
- 沉默陪伴：解锁连携【月下回旋】。

战斗点：BTL_SIDE_HH_01 记忆小妖 x3。

奖励：饰品【粉色风铃】，慧慧技能【清心铃】强化。

## 8.2 A 支线：沉稳的人也会害怕

触发：A 被救回后，在训练场对话。

核心：A 被抓后觉得自己拖累队伍，要求单独训练。

分支：
- 与 A 对练：BTL_SIDE_A_01，胜利后 `trust_a +2`。
- 让 A 休息：`mercy_score +1`，获得防御饰品。
- 请慧慧劝他：触发队伍三人对白。

奖励：A 技能【山崩】提前解锁。

## 8.3 葱葱支线：天剑阁来信

触发：葱葱好感 3 以上，神殿后回木桶镇。

核心：天剑阁来信要求葱葱回去继任，但葱葱不想放弃队伍。

分支：
- 支持他留下：`trust_congcong +2`。
- 劝他回去看看：开启天剑阁短地图。
- 让慧慧决定：特殊喜剧对白，`trust_huihui +1`, `trust_congcong +1`。

战斗点：BTL_SIDE_CC_01 天剑阁试炼影 x1。

奖励：葱葱技能【破绽看穿】。

## 8.4 sun 支线：旁观者

触发：生命之泉后，神殿大殿与 sun 对话。

核心：sun 质疑神殿长期旁观是否也是导致 xiaoai 堕落的原因。

分支：
- “你可以改变。” → `trust_sun +2`。
- “神殿也有错。” → sun 沉默，`mercy_score +1`。
- “我不关心神殿。” → 支线提前结束。

战斗点：BTL_SIDE_SUN_01 旁观之影。

奖励：sun 技能【人的祈愿】，真结局阶段增益。

## 8.5 xiaoai 支线：残光回忆

触发：普通结局后继续游戏，或真结局条件达成后自动。

收集 5 个记忆碎片：
1. 迷惘界看到权杖。

3. 轮回道正确回答第二句。
